# DevOps Git Version Control Project

## Project Overview
This project demonstrates Git and GitHub best practices for managing a DevOps project using version control.

## Objectives
- Understand Git fundamentals
- Create and manage branches
- Follow a feature-based Git workflow
- Use Pull Requests
- Merge branches
- Resolve merge conflicts
- Use .gitignore
- Create Git tags
- Document tasks using Markdown

## Tools Used
- Git
- GitHub
- Ubuntu Linux
- AWS EC2
- Markdown

## Branching Strategy

| Branch | Purpose |
|---|---|
| main | Stable production-ready code |
| dev | Development and integration |
| feature/* | Individual feature development |

## Git Workflow

feature -> dev -> main
