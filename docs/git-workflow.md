# Git Workflow Documentation

## What is Git?
Git is a distributed version control system used to track changes in source code.

## What is a Repository?
A Git repository stores project files and their version history.

## What is a Commit?
A commit records changes made to files in a Git repository.

## What is a Branch?
A branch provides an independent line of development.

## What is Git Merge?
Git merge combines changes from one branch into another branch.

## What is Git Rebase?
Git rebase reapplies commits on top of another branch and helps maintain a linear project history.

## What is a Pull Request?
A Pull Request is a request to merge changes from one branch into another on GitHub.

## What is a Merge Conflict?
A merge conflict occurs when Git cannot automatically combine changes from different branches.

## What are Git Tags?
Git tags identify important commits, commonly used for software releases.

## What is Git Stash?
Git stash temporarily stores uncommitted changes so they can be restored later.

## What is .gitignore?
The .gitignore file specifies files and directories that Git should not track.
